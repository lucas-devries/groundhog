# groundhog

Lokales CLI, das die Tickets einer Spec deterministisch und AFK abarbeitet. Baut auf den Matt-Pocock-Skills auf.

## Agent skills

### Issue tracker

Issues und Specs liegen in GitHub Issues (`gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Die fünf kanonischen Rollen mit Standardnamen. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` und `docs/adr/` im Repo-Root. See `docs/agents/domain.md`.
